# Bumble Marketing OS

Операционная система маркетинга Bumble Coffee (зонт — Black Phoenix).
Единое рабочее пространство команды: задачи, контент, бренд, инфлюенсеры, PR,
аналитика, автоматизация, планирование.

## Как открыть

**По ссылке (для всей команды):** если для репозитория включён GitHub Pages —
страница доступна по адресу вида `https://<домен>/bumble/`.

**Локально:** нужен любой локальный сервер, потому что браузер не отдаёт
дополнительные файлы при открытии через `file://`.

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000/bumble/
```

## Что где лежит

```
bumble/
  index.html              — каркас приложения, порядок подключения файлов
  assets/css/app.css      — оформление; свёрстано по Visual Code Book v1.0
  assets/js/core.js       — хранилище, роутер, оценки ICE/RICE, справочники
  assets/js/ui.js         — таблицы, канбан, модалки, фильтры, чипы
  assets/js/app.js        — запуск, поиск, тема, экспорт/импорт
  assets/js/data/         — содержимое системы (правится текстом)
  assets/js/views/        — семнадцать экранов
```

## Где менять содержимое

Всё содержательное — обычные `.js`-файлы в `assets/js/data/`, читаются
как текст:

| Файл | Что внутри |
|---|---|
| `brand.js` | Позиционирование, ToV, вкусы, палитра, пять законов, слоганы, питчи |
| `team.js` | Роли, зоны ответственности, ритуалы, KPI, ёмкость |
| `channels.js` | Двадцать направлений Marketing HQ: владелец, ритм, стандарт, чек-лист |
| `banks.js` | Банки крючков, сценариев, Reels, Stories, локаций, музыки и прочего |
| `content.js` | Воронка, рубрикатор, серии, недельная сетка, правила публикации |
| `influencers.js` | Тиры, чек-лист скоринга, пайплайн, шаблоны outreach, амбассадоры |
| `pr.js` | Типы медиа, поводы, шаблон релиза, правила |
| `launch.js` | Тринадцать этапов запуска, семь фаз кампании |
| `knowledge.js` | Регламенты, SOP, чек-листы, 32 возражения, 42 FAQ, онбординг |
| `automation.js` | Процессы к автоматизации, стек, порядок внедрения |
| `prompts.js` | Библиотека промптов по ролям + блок контекста бренда |
| `growth.js` | Курируемые банки идей и оси генератора гипотез |
| `tasks.js`, `ideas.js`, `audit.js` | Стартовое наполнение досок |

Файлы `tasks.js`, `ideas.js`, `influencers.js` (карточки), `audit.js` задают
только **первое** наполнение. Дальше данные живут в браузере и правятся из
интерфейса.

## Где живут данные

В `localStorage` браузера, ключ `bumbleOS.v1`. Это значит:

- у каждого свой экземпляр — общей базы нет;
- очистка данных сайта стирает всё;
- обмен состоянием — через кнопки **Экспорт** / **Импорт** слева внизу.

**Делайте экспорт каждую пятницу вместе с недельной сводкой.** Это десять
секунд и единственная защита от потери работы.

## Горячие клавиши

- `Ctrl/Cmd + K` — поиск по всей системе, включая банки, возражения и промпты
- `N` — новая задача
- `Esc` — закрыть окно

## Правила, зашитые в систему

Интерфейс сам следует бренду и не даёт от него отклониться:

- линия горизонта на 61,8% в карточках, плитках и логотипе;
- только тёплый спектр — холодных цветов нет ни в статусах, ни в графиках;
- всё появляется снизу вверх, `cubic-bezier(.16,1,.3,1)`, 480/220 мс;
- три зерна вместо буллитов, загрузки и спиннеров;
- пустой экран — «Свет ещё не поднялся» и одна кнопка;
- ошибка — что случилось и что нажать, без извинений и юмора.
