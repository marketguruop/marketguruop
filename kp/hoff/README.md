# HOFF × MarketGuru — коммерческое предложение

- `HOFF_MarketGuru_KP.pdf` — актуальная версия (25 слайдов).
- `HOFF_MarketGuru_KP_original.pdf` — версия до правок.
- `slides-4-8.html` — исходник пересобранных слайдов 4 и 8 (960×540 px, печать в 720×405 pt).

## Что изменено

**Слайд 4 «Масштаб и признание»** — добавлен блок «Нам доверяют» с компаниями:
Splat, Kari, Zarina, Befree, Технопарк, Melon Fashion Group.

**Слайд 8 «Финансы, поставки и ценообразование»** — в карточку «Репрайсер»
добавлены две стратегии:
- стратегия по конкурентам — цена на 1 ₽ ниже выбранных конкурентов;
- стратегия изменения цены по времени — для повышения средней медианной цены.

Карточки на слайде 8 подняты вверх, чтобы вместить новый текст.

## Пересборка

```sh
chromium --headless --no-pdf-header-footer --print-to-pdf=new.pdf slides-4-8.html
```

Затем страницы 1 и 2 из `new.pdf` подставляются на места слайдов 4 и 8 исходного
PDF (PyMuPDF `show_pdf_page`), остальные 23 слайда не пересобираются.
